# Leonida Field Guide

An offline, printed-field-guide-style companion for the 55 PlayStation 5 trophies of Grand Theft Auto VI. It pairs a filterable checklist with a nine-stage roadmap, a missable-aware tracker and a hand-written, cited guide for every trophy. Progress stays in your browser.
